# What exactly is this?
A mental health platform dedicated to students in which they can checkin on how they are currently feeling in the moment. 
The user will also be able to complete exercises like breathing. 
Users can participate in "question of the day" where people can comment anonymously. 
There will be an acheivement/badge system
Lulora is the mascot of the site that is a panda. the user can change its name and their pronouns. It will talk to them from time to time.
Affirmation explorer
The user can check in at any point in the day. each day will have a list of checkins
The user will be able to look for hotlines on the site
