**Tell us about a technical project you are proud of or a difficult problem you have solved. What did you contribute, what challenges did you run into, and how did you work through them? (700 character limit)**
Recently I worked on my own search engine from scratch called Sift which is a concurrent web crawler, page indexer and ranker combined. I was having a problem of my crawlers were getting clogged up by a very small number of host servers with a large amount of urls. rewrote the frontier using a global host map, ready queue, and cooldown min-heap to make scheduling more reliable and efficient. I then used metrics to identify DNS failures as a major bottleneck and added a negative DNS cache. These changes reduced a 20,000-URL crawl from ~7 minutes to ~2 minutes.
