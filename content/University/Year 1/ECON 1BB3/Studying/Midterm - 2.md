## Chapter 4: GDP and Economic Measurement
### Key Concepts
- [x] GDP Definition: Market value of all final goods and services produced in a country during a period
- [x] Final vs. Intermediate Goods: Only final goods count; intermediate goods would cause double-counting
- [x] GDP Components: $\text{GDP} = C + I + G + NX$
- [x] Consumption $(C)$: Household spending
- [x] Investment $(I)$: Physical capital, residential construction, and inventory changes (NOT stock purchases)
- [x] Government Purchases $(G)$: Government spending on goods/services
- [x] Net Exports $(NX)$: Exports - Imports

### Important Distinctions
- [x] Nominal GDP = current year prices
- [x] Real GDP = base year prices (adjusts for inflation)
- [x] GDP Deflator: $\text{GDP Deflator} = \frac{\text{Nominal GDP}}{\text{Real GDP}} \times 100$
- [x] Value-Added Method: Sum of value added at each production stage
- [ ] What's NOT in GDP: Intermediate goods, used goods, stock/financial transactions, household production, underground economy

### Calculations
- [x] Computing nominal GDP
- [x] Computing real GDP
- [x] GDP deflator calculations
- [x] Growth rate: $\text{Growth Rate} = \frac{\text{GDP}_2 - \text{GDP}_1}{\text{GDP}_1} \times 100$

## Chapter 5: Unemployment and Inflation

### Unemployment Formulas
- [x] Labor Force: $\text{LF} = \text{Employed} + \text{Unemployed}$
- [x] Unemployment Rate: $\text{UR} = \frac{\text{Unemployed}}{\text{Labor Force}} \times 100$
- [x] Labor Force Participation Rate: $\text{LFPR} = \frac{\text{Labor Force}}{\text{Working-Age Population}} \times 100$
- [x] Employment-Population Ratio: $\text{EPR} = \frac{\text{Employed}}{\text{Working-Age Population}} \times 100$

### Types of Unemployment
- [x] Frictional: Short-term job searching
- [x] Structural: Skills mismatch, need retraining
- [x] Cyclical: Due to recessions
- [x] Natural Rate: Frictional + Structural (full employment)

### Inflation Concepts
- [x] CPI (Consumer Price Index): Average prices for typical household basket
- [x] Inflation Rate: $\text{Inflation Rate} = \frac{\text{CPI}_2 - \text{CPI}_1}{\text{CPI}_1} \times 100$
- [x] Nominal variables = current prices
- [x] Real variables = adjusted for inflation
- [x] Real Wage: $\text{Real Wage} = \frac{\text{Nominal Wage}}{\text{CPI}} \times 100$
- [x] Real Interest Rate: $r = i - \pi$ where $r$ = real rate, $i$ = nominal rate, $\pi$ = inflation rate

### Key Relationships
- [x] Higher unexpected inflation: borrowers gain, lenders lose
- [x] Lower unexpected inflation: borrowers lose, lenders gain
- [x] Minimum wage effects on unemployment
- [x] Problems with CPI as measure of unemployment

## Chapter 6: Long-Run Economic Growth

### Key Concepts
- [x] Potential GDP: GDP when all firms produce at capacity
- [x] Real GDP Growth Rate: $\text{Growth Rate} = \frac{\text{GDP}_2 - \text{GDP}_1}{\text{GDP}_1} \times 100$
- [x] Average annual growth rate calculation

### Determinants of Growth
- [x] Capital (physical and human)
- [ ] Labor productivity
- [x] Technology
- [x] Human capital = knowledge/skills from education

### Loanable Funds Market
- [x] Supply of loanable funds = Household saving
- [x] Demand for loanable funds = Firms borrowing for investment
- [x] Private Saving: $S_{\text{private}} = Y - C - T$
- [x] Public Saving: $S_{\text{public}} = T - G - TR$
- [x] Total Saving: $S = S_{\text{private}} + S_{\text{public}}$
- [x] In closed economy: $S = I$
- [x] Investment-saving equality: $I = Y - C - G$

### Government Budget
- [x] Budget deficit: $T < (G + TR)$
- [x] Budget surplus: $T > (G + TR)$
- [x] Balanced budget: $T = (G + TR)$

### Important Relationships
- [x] Higher interest rates → less borrowing → less investment
- [x] Business cycle phases: peak → recession → trough → expansion
- [x] Effect of business taxes on loanable funds market
- [x] Effect of expected economic expansion on loanable funds market

### Financial System
- [x] Provides liquidity to savers
- [x] Provides information about borrowers
- [x] Provides risk sharing opportunities
- [x] Does NOT guarantee full insurance against loss

## Chapter 7: Economic Growth Model

### Production Function
- [ ] Per-worker production function: $\frac{Y}{L} = f\left(\frac{K}{L}, \text{technology}\right)$
- [ ] Increases in capital per worker → diminishing returns
- [ ] Technological change shifts entire production function upward
- [ ] Movement along curve vs. shift of curve

### Growth Theories
- [ ] Solow Growth Theory: Focus on capital accumulation and technology
- [ ] New Growth Theory: Knowledge capital is key; R&D drives growth
- [ ] Knowledge capital is nonrival and nonexcludable
- [ ] Firms underinvest in R&D because others can access it

### Factors Determining Labor Productivity
- [ ] Quantity of capital per hour worked
- [ ] Technological change
- [ ] Trade (not efficiency wages)

### Government Policies for Growth
- [ ] Education subsidies
- [ ] R&D subsidies
- [ ] Patent and copyright protection
- [ ] Strong property rights and rule of law
- [ ] Health improvements (vaccinations, clean water)
- [ ] Tax incentives for savings and investment

- [ ] Foreign Portfolio Investment: Buying stocks/bonds from another country
- [ ] Technology transfer between countries
- [ ] Low-income countries can catch up (convergence theory)

## Chapter 8: Aggregate Expenditure Model

### Aggregate Expenditure Components
- [ ] $AE = C + I + G + NX$
- [ ] Consumption function: $C = \text{Autonomous Consumption} + \text{MPC} \times \text{Disposable Income}$
- [ ] Planned investment (not actual investment with unplanned inventory changes)

### Key Concepts
- [ ] Marginal Propensity to Consume: $\text{MPC} = \frac{\Delta C}{\Delta Y}$
- [ ] Marginal Propensity to Save: $\text{MPS} = \frac{\Delta S}{\Delta Y}$
- [ ] $\text{MPC} + \text{MPS} = 1$
- [ ] Slope of consumption function = MPC
- [ ] Slope of aggregate expenditure line = MPC

### Determinants of Consumption
- [ ] Increase in household wealth → increase consumption
- [ ] Increase in interest rates → decrease consumption
- [ ] Increase in expected future income → increase consumption
- [ ] Increase in current disposable income → increase consumption
- [ ] Increase in price level → decrease consumption

### Determinants of Investment
- [ ] Lower real interest rate → increase investment
- [ ] Increased optimism about future demand → increase investment
- [ ] Higher corporate income tax → decrease investment

### 45-Degree Line Diagram
- [ ] Equilibrium: Where $AE = Y$ (aggregate expenditure equals GDP)
- [ ] Above 45° line: $AE > Y$ → inventories fall → GDP rises
- [ ] Below 45° line: $AE < Y$ → inventories rise → GDP falls
- [ ] 45° line shows all points where $AE = Y$

### Inventories
- [ ] Unplanned increase in inventories → actual investment > planned investment → GDP will decrease
- [ ] Unplanned decrease in inventories → actual investment < planned investment → GDP will increase
- [ ] Firms keep inventories to: provide selection, store excess production, meet irregular customer demand
- [ ] Goods produced in exact amounts matching customer demand = NOT a reason for inventories

### Multiplier Effect
- [ ] Multiplier formula: $\text{Multiplier} = \frac{1}{1 - \text{MPC}} = \frac{1}{\text{MPS}}$
- [ ] Change in equilibrium GDP: $\Delta Y = \text{Multiplier} \times \Delta \text{Autonomous Spending}$
- [ ] Example: If $\text{MPC} = 0.8$, then $\text{Multiplier} = \frac{1}{1-0.8} = 5$
- [ ] Larger multiplier → more severe recessions (small spending changes cause large GDP changes)

### Equilibrium GDP Calculations
- [ ] In equilibrium: $Y = C + I + G + NX$
- [ ] With consumption function: $Y = C_0 + \text{MPC}(Y - T) + I + G + NX$
- [ ] Solving for $Y$: $Y = \frac{1}{1-\text{MPC}}(C_0 + I + G + NX - \text{MPC} \times T)$
- [ ] In closed economy with no government: $Y = C + I$

### Net Exports Determinants
- [ ] Growth rate of US GDP relative to other countries
- [ ] Exchange rate between currencies
- [ ] Growth rate of US price level relative to other countries
- [ ] NOT determined by interest rate directly
